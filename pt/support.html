Perguntas Frequentes (FAQ)

Encontre abaixo as respostas para as perguntas e problemas mais comuns.

Porque é que recebo uma mensagem "Deve instalar o .NET Desktop Runtime" ao abrir o software?

O DataSynth Pro é construído sobre a robusta plataforma .NET 8.0 para garantir o máximo desempenho e precisão. Se este pré-requisito não estiver instalado no seu sistema Windows, verá este aviso. Basta clicar no botão "Transferir agora" (Download it now) na janela de aviso, seguir as instruções do instalador da Microsoft e reiniciar o DataSynth Pro.

Como posso encontrar o meu Código de Máquina?

Pode clicar no botão Register (Registar) na interface principal do software, e o código de máquina será exibido na janela.

Posso utilizar o software offline?

Sim, absolutamente. O DataSynth Pro foi concebido para funcionar 100% offline. Priorizamos a privacidade dos seus dados, pelo que não há telemetria de dados ou requisito de ligação à Internet em segundo plano. Pode gerar com segurança estruturas de dados clínicas ou financeiras sensíveis diretamente na sua máquina local.

Os dados gerados pelo software são diferentes de cada vez?

Sim, os dados gerados pelo programa são diferentes de cada vez. Mesmo que os mesmos valores-alvo exatos sejam definidos, há infinitas soluções matematicamente possíveis. Pode utilizá-lo com confiança; não será idêntico aos dados de mais ninguém.

Pode ser utilizado em Apple macOS?

Sim, os utilizadores de Apple macOS podem utilizar este software executando o Windows através de uma máquina virtual. O software de máquina virtual é de código aberto e pode ser descarregado gratuitamente.

Porque é que o sistema apresenta a mensagem "O Smart App Control bloqueou uma aplicação que pode ser insegura"?

Le logiciel n'a pas versé de redevances aux éditeurs de solutions de sécurité, ce qui peut entraîner une fausse interception. Vous pouvez résoudre ce problème en ajustant les paramètres suivants : Système > Confidentialité et sécurité > Sécurité Windows > Contrôle des applications et du navigateur > Paramètres Smart App Control > Désactivé (Off). Si un autre logiciel de sécurité signale une interception, veuillez ajouter l'application à la liste des exclusions/applications approuvées.
