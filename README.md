# 📊 DataSynth Pro: Advanced Statistical Data Generation Engine

**DataSynth Pro** is a Windows application designed to generate realistic, mathematically sound synthetic datasets that perfectly align with **IBM SPSS** outputs. 

👉 **[Visit the Official Website: www.datasynthpro.com](https://www.datasynthpro.com)**

## 🚀 Core Value
Stop manually tweaking mock data. Input your target statistical thresholds (e.g., target p-values, Hazard Ratios, or precise ROC curve AUCs), and our engine will reverse-engineer the distribution and generate the raw dataset in seconds.

## ✨ Key Features
* **Extensive Tests:** Independent/Paired t-Tests, ANOVAs (One-Way/Two-Way/Repeated Measures), Chi-Square, and Non-parametric tests.
* **Advanced Regression:** Data synthesis for Binary Logistic, Multiple Linear, and Cox Proportional Hazards.
* **Visual Tuning:** Drag sliders to adjust distributions and watch ROC/AUC values update in real time.
* **Instant Export:** One-click export to standard Excel spreadsheets.
