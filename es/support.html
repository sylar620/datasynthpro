Preguntas Frecuentes (FAQ)

A continuación encontrará las respuestas a las preguntas y problemas más comunes.

¿Por qué aparece el mensaje "Debe instalar .NET Desktop Runtime" al abrir el software?

DataSynth Pro está desarrollado sobre la robusta plataforma .NET 8.0 para garantizar el máximo rendimiento y precisión. Si este requisito previo no está instalado en su sistema Windows, aparecerá este aviso. Simplemente haga clic en el botón "Descargar ahora" en la ventana de aviso, siga las instrucciones del instalador de Microsoft y luego vuelva a abrir DataSynth Pro.

¿Cómo puedo encontrar mi código de máquina?

Puede hacer clic en el botón Register (Registrar) en la interfaz principal del software, y el código de máquina se mostrará en la ventana.

¿Puedo utilizar el software sin conexión?

Sí, absolutamente. DataSynth Pro está diseñado para funcionar al 100% fuera de línea. Damos máxima prioridad a la privacidad de sus datos: no hay telemetría de datos ni obligación de conexión a Internet en segundo plano. Puede generar de forma segura estructuras de datos clínicos o financieros sensibles directamente en su máquina local.

¿Los datos generados por el software son diferentes cada vez?

Sí, los datos generados por el programa son diferentes cada vez. Incluso si se configuran exactamente los mismos valores objetivo, existe una infinidad matemática de soluciones posibles. Puede usarlo con total confianza; sus datos no serán idénticos a los de ningún otro usuario en ningún caso.

¿Se puede utilizar en Apple macOS?

Sí, los usuarios de Apple macOS pueden usar este software ejecutando Windows a través de una máquina virtual. El software de máquina virtual es de código abierto y se puede descargar de forma gratuita.

¿Por qué el sistema muestra "Smart App Control bloqueó una aplicación potencialmente peligrosa"?

El software no ha pagado regalías a los proveedores de soluciones de seguridad, lo que puede provocar una falsa interceptación. Puede resolver este problema ajustando la siguiente configuración: Sistema > Privacidad y seguridad > Seguridad de Windows > Control de aplicaciones y navegador > Configuración de Smart App Control > Desactivado (Off). Si otro software de seguridad informa una interceptación, agregue la aplicación a la lista de exclusión/aprobadas.
